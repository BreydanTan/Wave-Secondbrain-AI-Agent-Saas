## 📦 数据流动：外卖配送流程

### 类比：用户操作 = 点外卖

当你在Wave AI中"发送一条消息"时，就像在美团点外卖：

```
1️⃣ 顾客下单（用户操作）
   你：在聊天框输入"帮我创建一条笔记：学习Next.js"
   ↓
   点击"发送"按钮

2️⃣ 美团APP（前端）
   文件: app/(main)/chat/[id]/page.tsx
   React组件接收点击事件
   ↓
   调用 useChat hook
   ↓
   发送 HTTP POST 请求到 /api/chat

3️⃣ 骑手接单（API路由）
   文件: app/api/[[...route]]/route.ts
   Hono框架接收请求
   ↓
   验证用户身份（BetterAuth）
   ↓
   调用 chatHandler 函数

4️⃣ 餐厅做菜（AI处理）
   文件: lib/ai/index.ts
   调用 streamText 函数
   ↓
   AI分析："这个请求需要使用create-note工具"
   ↓
   调用 createNoteTool

5️⃣ 仓库操作（数据库）
   文件: lib/ai/tools/create-note.ts
   使用 Prisma 创建笔记
   ↓
   await prisma.note.create({
     data: { userId, title, content }
   })

6️⃣ 骑手送餐（响应返回）
   数据库返回新笔记对象
   ↓
   AI生成回复："已为您创建笔记"
   ↓
   流式传输响应到前端

7️⃣ 顾客收餐（界面更新）
   前端接收流式数据
   ↓
   实时显示AI回复
   ↓
   用户看到："✅ 已为您创建笔记：学习Next.js"
```

### 数据流向图

```
用户点击
  │
  ├─ 点击"发送消息"按钮
  │     ↓
  │  React组件 (chat/[id]/page.tsx)
  │     ↓
  │  useChat() hook
  │     ↓
  │  fetch('POST /api/chat')
  │     ↓
  ├─ HTTP请求发送
  │     ↓
  │  Hono API路由 (api/[[...route]]/route.ts)
  │     ↓
  │  认证中间件检查
  │     ↓
  │  chatHandler 处理
  │     ↓
  │  streamText() AI处理
  │     ↓
  ├─ AI决定调用工具
  │     ↓
  │  createNoteTool.execute()
  │     ↓
  │  prisma.note.create()
  │     ↓
  ├─ 数据库操作
  │     ↓
  │  PostgreSQL 插入数据
  │     ↓
  │  返回新笔记对象
  │     ↓
  ├─ 响应返回
  │     ↓
  │  AI生成文本响应
  │     ↓
  │  流式传输到前端
  │     ↓
  ├─ 界面更新
  │     ↓
  │  React组件接收流
  │     ↓
  │  实时显示消息
  │     ↓
  └─ 用户看到结果
```

## 🚦 请求-响应流程：交通信号系统

### 类比：API请求 = 开车去目的地

```
1️⃣ 起点：用户在浏览器
   📍 你在家（浏览器）
   🚗 决定去"AI聊天商店"

   代码:
   const response = await fetch('/api/chat', {
     method: 'POST',
     body: JSON.stringify({ message: '你好' })
   })

2️⃣ 上路：HTTP请求
   🛣️ 走HTTP公路
   🚦 经过认证检查站（BetterAuth中间件）

   如果没有通行证（未登录）→ 被拦下，返回401
   如果有通行证（已登录）→ 放行

   代码位置: app/api/[[...route]]/route.ts:32

3️⃣ 到达：API端点
   🏪 到达"/api/chat"商店
   🔍 店员检查你的请求

   检查内容：
   - 消息内容是否有效
   - 用户订阅是否足够

   代码位置: app/api/[[...route]]/chat.ts:45

4️⃣ 处理：业务逻辑
   👨‍💼 店员去仓库拿货（调用AI）
   🤖 AI处理你的消息
   📦 打包结果

   代码位置: lib/ai/index.ts:78

5️⃣ 返回：响应回传
   🚚 结果装车送回你家
   📬 浏览器收到响应

   响应格式:
   {
     "message": "你好！有什么可以帮你？",
     "toolCalls": []
   }

6️⃣ 显示：界面更新
   🖥️ 浏览器显示AI回复
   ✅ 任务完成
```

### 状态码含义（交通信号灯）

| 状态码 | 含义 | 交通类比 | 处理方式 |
|-------|------|---------|---------|
| **200** | 成功 | 🟢 绿灯，顺利通过 | 正常显示结果 |
| **201** | 已创建 | 🟢 绿灯，且目的地已建好 | 显示新创建的资源 |
| **400** | 请求错误 | 🟡 黄灯，请求有问题 | 显示错误提示 |
| **401** | 未认证 | 🔴 红灯，没有通行证 | 跳转到登录页 |
| **403** | 无权限 | 🔴 红灯，通行证不够级别 | 显示"无权限" |
| **404** | 未找到 | 🟠 橙灯，目的地不存在 | 显示"页面不存在" |
| **500** | 服务器错误 | ⚫ 故障，路上出事故了 | 显示"系统错误" |
