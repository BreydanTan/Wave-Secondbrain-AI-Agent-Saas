# 🔰 基础操作提示词 / Basic Prompts

> **可直接复制使用的AI协作提示词**

---

## 🚀 环境搭建

### 安装依赖遇到问题

```
我在运行 npm install 时遇到以下错误：
[粘贴错误信息]

我的环境：
- Node版本: [运行 node -v]
- npm版本: [运行 npm -v]
- 操作系统: [Windows/Mac/Linux]
- 网络状况: [正常/需要代理]

请帮我诊断并提供解决方案。
```

### 启动项目失败

```
我运行 npm run dev 后遇到错误：
[粘贴完整错误堆栈]

项目信息：
- 项目路径: [你的项目路径]
- .env.local 配置:已设置 / 未设置]
- 数据库: [已初始化 / 未初始化]

请给出具体的修复步骤。
```

## 📁 文件操作

### 找不到某个功能的代码

```
在Wave AI项目中，我想找到[具体功能]的代码位置。

功能描述: [详细描述，如"用户登录按钮"]

请告诉我：
1. 这个功能在哪个文件中
2. 具体在第几行
3. 相关的文件有哪些
```

### 理解某个文件的作用

```
请帮我理解 [文件路径] 这个文件的作用。

文件内容（前50行）：
[粘贴代码]

请用简单的语言解释：
1. 这个文件是做什么的
2. 主要导出了哪些函数/组件
3. 它被哪些文件使用
```

## ✏️ 代码编辑

### 修改文本内容


### 修改样式

```
我想修改 [组件/页面] 的样式。

当前样式: [描述现在的样子]

具体要求：

```

### 查看数据库内容

```

请提供Prisma代码来创建这条记录。
```

## 🎨 UI组件

### 使用现有组件

```
我想使用项目中的 [组件名] 组件。

组件位置: [如果知道的话]
使用场景: [在哪里使用，做什么]

请提供：
1. 组件的完整路径
2. 使用示例代码
3. 可用的Props说明
```

### 修改组件

```
我想修改 [组件名] 组件的 [行为/样式]。

当前代码: [粘贴相关代码]
期望改成: [描述期望]

请提供修改建议和代码。
```

---

## 使用技巧

1. **提供具体信息**: 错误信息、代码片段、文件路径
2. **说明环境**: 操作系统、Node版本、浏览器
3. **描述已尝试**: 你已经试过哪些方法
4. **明确目标**: 你想达成什么效果
