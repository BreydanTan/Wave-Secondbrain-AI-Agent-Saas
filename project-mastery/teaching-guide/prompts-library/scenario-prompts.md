## 场景1：我想添加"收藏笔记"功能

```
我想为Wave AI添加"收藏笔记"功能。

功能需求：
- 用户可以收藏/取消收藏笔记
- 有单独的"我的收藏"页面查看所有收藏
- 收藏的笔记显示⭐️标记

技术实现思路（需要你帮我确认）：
1. 数据库添加Bookmark表
2. 创建收藏/取消收藏API
3. 笔记卡片添加收藏按钮
4. 创建收藏列表页面

参考文档：
- project-mastery/analysis/01-database-analysis.md（数据库设计）
- project-mastery/analysis/02-backend-analysis.md（API设计）

请帮我：
1. 确认实现思路是否正确
2. 提供详细的实现步骤（数据库→后端→前端）
3. 每一步给出具体代码
```

**预期输出**: 完整的实现方案和代码

## 使用建议

1. **场景化提示词的优势**:
   - 描述完整需求
   - 包含上下文信息
   - 明确参考文档
   - 列出具体期望

2. **如何自定义**:
   - 复制模板
   - 填入你的具体需求
   - 添加项目相关信息
   - 明确输出期望

3. **获得更好的回答**:
   - 提供错误信息
   - 说明已尝试的方法
   - 附上相关代码
   - 明确卡在哪一步
