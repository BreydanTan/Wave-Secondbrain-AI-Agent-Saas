## 使用模式

### 完整开发流程

1. **需求分析**
   ```
   使用上述提示词描述需求
   → AI给出实现方案
   ```

2. **分步实现**
   ```
   Step 1: 数据库模型
   Step 2: 后端API
   Step 3: 前端组件
   Step 4: 集成测试
   ```

3. **调试和优化**
   ```
   使用[调试提示词](./debugging-prompts.md)
   ```
