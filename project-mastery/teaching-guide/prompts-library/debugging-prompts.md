## 📋 调试检查清单

遇到任何错误时，先完成这个清单：

**基础检查**
- [ ] 开发服务器是否运行（`npm run dev`）
- [ ] 浏览器Console是否有错误
- [ ] 终端是否有错误
- [ ] .env.local配置是否正确
- [ ] 数据库是否连接成功

**代码检查**
- [ ] TypeScript是否有类型错误
- [ ] 导入路径是否正确
- [ ] 函数调用是否正确
- [ ] 数据格式是否匹配

**网络检查**
- [ ] API端点是否正确
- [ ] 请求方法是否正确（GET/POST/etc.）
- [ ] 请求头是否正确
- [ ] 响应状态码是什么

**数据库检查**
- [ ] Schema是否正确
- [ ] 数据是否存在
- [ ] 关系是否正确配置
- [ ] Prisma Client是否已生成

完成检查清单后再使用上述提示词寻求帮助，会更高效！
